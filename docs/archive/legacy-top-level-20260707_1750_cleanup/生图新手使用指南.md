## 1. 这份文档是给谁看的

如果你：

- 不懂 AI 模型名
- 不会写英文 prompt
- 只想“说一句话，让系统帮你画图”
- 想在网页、Chatbox 或 Codex 里直接出图

那么这份文档就是给你的。

## 2. 先记住一句话

**你不需要懂技术，只要会描述你想要什么图就行。**

最简单的结构就是：

> 画什么 + 什么风格 + 什么背景 + 什么颜色 + 用来做什么

例如：

> 帮我画一个白底、蓝色、极简风的科技头像，主体是一个圆形图标，干净、清晰、不要文字、不要水印。

## 3. 最推荐的方式：直接用网页

如果你是第一次用，优先打开这两个页面之一。

- `https://sub-lb.tap365.org/image-studio`
- `https://studio.tap365.org/`

这两个页面都已经确认能打开；至于页面里具体叫“生成”“新建”“图片”“编辑”还是别的名字，要以你当前看到的界面为准。

**小白优先级：网页 > Chatbox > 官方 Codex App。**

原因很简单：网页最直观，不用先配客户端。

### 操作步骤

1. 打开网页
2. 找到和“生成图片 / 图片 / 生图 / Create / Generate”相关的入口
3. 直接输入你想要的画面描述
4. 如果页面还有模型选择，优先用页面默认推荐项，不要自己乱改模型名
5. 点击生成
6. 等图片出来后下载或保存
7. 不满意就改一句话再生成一次

### 你可以直接照抄的提示词模板

#### 模板 1：头像

> 帮我画一个白底、蓝色、极简风的头像，主体是一个圆形人物剪影，干净、科技感、不要文字、不要水印。

#### 模板 2：商品图

> 帮我画一张电商商品主图，主体是一只白色咖啡杯，摆在石质桌面上，风格高级、明亮、干净、适合电商展示。

#### 模板 3：海报

> 帮我画一张活动海报，主题是春季新品发布会，风格现代、简洁、留白多，适合微信公众号封面。

#### 模板 4：图标

> 帮我画一个绿色叶子图标，扁平风格，白色背景，边缘干净，适合 App 图标使用。

## 4. 不会写 prompt 怎么办

直接用下面这个句式，把方括号里的内容换掉就行：

```text
帮我画一张【主体】，【风格】，【背景】，【颜色】，【用途】。
```

例如：

```text
帮我画一张蓝色圆形按钮，极简风，白色背景，适合网站首页图标。
```

### 想让图更好看，可以补这几类词

- 风格：极简、写实、卡通、赛博朋克、扁平、插画、摄影感
- 背景：白底、纯色、透明感、室内、户外、渐变背景
- 颜色：蓝色、绿色、黑金、暖色、莫兰迪色
- 用途：头像、海报、封面图、商品图、图标、Banner

## 5. 如果你想改一张已有图片

这类需求叫“图片编辑”或者“修图”。

你只需要做两件事：

1. 上传原图
2. 说明要改哪里

例如：

- “把背景改成白色”
- “把衣服颜色改成蓝色”
- “把左上角的文字去掉”
- “把这张图变得更明亮一点”

如果页面里有“遮罩 / 涂抹 / 局部修改”功能，就只圈出你想改的那一块；其他地方尽量不动。  
如果页面里没有这个功能，就先用普通编辑，把要求说清楚。

## 6. 在 Chatbox 里怎么用

这部分我本轮**没有**做客户端实测，所以只给通用思路。

如果你的 Chatbox 版本支持 OpenAI 兼容接口或图片能力，可以这样配：

### 基本配置

- Base URL：`https://sub-lb.tap365.org/v1`
- API Key：填写你的 SubLB Key
- Model：优先用页面/分组里推荐的图片模型
  - OpenAI 图片：`gpt-image-2`
  - Grok 图片：`grok-imagine-1.0`

### 使用方法

1. 在 Chatbox 里新建一个支持图片能力的会话
2. 选好上面的 Base URL 和 Key
3. 直接用中文说你想画什么
4. 如果版本里有“Images / 生图”入口，优先点那个
5. 如果只有聊天窗口，也可以先让它帮你把需求整理成更好的 prompt，再复制去网页生成

### 给 Chatbox 的一句话示例

> 帮我生成一张白底、蓝色、极简风的科技头像，主体是一个圆形图标，清晰、简洁、不要文字、不要水印。

## 7. 在官方 Codex App 里怎么用

这部分我本轮**没有**做客户端实测，所以也只给通用思路。

如果你用的是官方 Codex App，并且当前版本已经支持图片能力，最简单的办法也是直接说人话：

> 帮我画一个白底蓝色的极简图标，主体是一个圆形科技按钮，适合做网站头像。

Codex App 里你不需要先学模型名。你只要告诉它：

- 想画什么
- 要什么风格
- 背景要什么样
- 最终用在哪里

### 如果你想让它更稳一点

可以把要求拆成两句：

1. “先帮我整理成适合生图的描述”
2. “再按这个描述生成图片”

如果当前版本只有聊天能力，没有直接出图按钮，也可以先让它帮你整理 prompt，再复制去网页生成。

## 9. 小白最常见的 5 个问题

### 1）我是不是必须懂模型名？

不用。你只要会描述想要的图片就行。

### 2）我是不是必须会英文？

不用。中文就可以。

### 3）为什么我画出来的字不对？

图片模型对长文字、复杂中文排版不稳定。  
如果你要海报文案，建议先把文案单独写好，再让系统排版。

### 4）为什么图片不够像我想的那样？

你可以继续补充：

- 更具体的主体
- 更明确的风格
- 更明确的背景
- 更明确的用途

例如把“好看一点”改成：

> 极简、干净、白底、科技感、适合做网站首页图标

### 5）生成太慢怎么办？

先减少描述里的复杂条件，先做一个简单版本。

## 10. 安全提醒

- 不要上传敏感隐私照片
- 不要拿别人的头像、证件照、银行卡照片乱试
- 不要把真实 Key、密码、验证码发到公开聊天里
