# turing-sdk

`turing-sdk` is the Node.js SDK for Turing Code.

## Best starting points

- npm package: `https://www.npmjs.com/package/turing-sdk`
- install page: `https://turing.tap365.org/`
- public releases: `https://github.com/mason0510/sublb-client/releases`

## Core APIs

- `query`
- `stream`
- `streamText`

## Use cases

- Node.js services
- scripts and automation
- workers and queues
- programmatic integrations that need to drive Turing from code

## Notes

- this package is for Node.js, not browser-side direct use
- installing `turing-sdk` also installs `turing-code`
